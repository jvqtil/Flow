# Flow

Notes app for Android. Fully native. Just your notes, no bullshit

## Features

- Minimal note editor
- Local-only storage
- Smooth, yet fast animations
- Material UI
- Dynamic colors on Android 12+
- Predictive back gesture support (Android 16+)
